## What shipped

1. **Bidirectional debt + reversal** (`SocialEvent.CollectDebtEdges`). Debt (`ev.a`=debtor, `ev.b`=creditor)
   now emits BOTH `creditor→debtor` (score 60) and `debtor→creditor` (score 58), like feuds — so a debtor can
   kill the creditor to escape the debt. The gossip already handled both roles, so no gossip change was needed.

2. **Threat-note addressee + correct "To" connection** (`ClueInjector`, the anon threat notes). Two changes:
   - The note body now opens with the recipient's name as a **clickable `CitizenLink`** salutation
     ("`Heidi Kennedy,`\n\n`Settle your debt…`"), so it's clear who it threatens even in a shared space.
     `<link>` renders fine under the handwriting font (`isHandwriting` is only a metadata flag; TMP rich-text
     parses regardless — the redundancy list proved this).
   - A **"To" connection is drawn EXPLICITLY** to the recipient via `AddCitizenConnection` (the layoffs/eviction
     mechanism), with **`receiver=null` at placement**. The recipient (`noteOwner`) is persisted in the note's
     `pids` so both the salutation and the "To" survive reload; the writer **"From" stays hidden**.

3. **Home/work placement for Money + Feud clues** (`InjectAnonThreatNote`, `InjectEviction`). The anon notes and
   the eviction plan can now land at the victim's **home OR work** (`WorkplaceClueShare`), matching affair/
   workplace clues — **except** the debt-reversal note (where the debtor is the *killer*), which stays at the
   debtor's **home** (`allowWork = Motive.Same(noteOwner, murderVictim)`).

4. **Gossip naturalization pass** (`SocialEvent.TestimonyAbout`, `Interrogation.AffairLine`, user-directed):
   - **No em-dashes**, no trailing flavour clauses ("real bad blood there", "nasty business", etc.).
   - **Promotions/layoffs are pointer-only** — no company name, no promotee name, no jealousy framing (the
     player infers rivalry; the clue carries identities).
   - **Rent arrears** may mention "rent" in one variant; **feud/debt name the other party**.
   - `AffairLine` cycles 3 variants and appends "Can't imagine `<partner>` took that well." **only if a partner
     exists** (fixes the no-partner / multi-lover breakage).

5. **Debt gossip collapse** (`Interrogation.ComposeLines` + `DebtOwedLine`/`DebtOwedToThemLine`). Multiple debts
   about one subject merge into at most **two list bubbles** (like affairs): "they owed X and Y money" (subject
   is the debtor) / "X and Y owed them money" (subject is the creditor). Variants are number-agnostic.

6. **Repeated-hearsay de-dupe** (`Interrogation.DedupeHearsayTail` + per-line seed offsets). The tail
   ", from what I hear." is kept on the first bubble that uses it and trimmed from later ones, and the two debt
   bubbles + multiple workplace/feud lines use offset seeds so back-to-back bubbles don't pick the same shape.

7. **Stall watchdog** (`MurderWatchdog.cs`, new). Recovers a **mod** motive-murder soft-locked in `executing`
   (killer reaches the victim but never lands a lethal blow — observed as the killer whiffing/"punching" with a
   razor blade, victim fleeing, forever). Fires **only** for `MurderSelector.OverriddenVictimIds`, **only** when
   the killer is **co-located** with the victim, and **only** when the victim's health is untouched (a genuine
   whiff-stall). Force-finishes via `Actor.RecieveDamage(…, enableKill:true)` then forces `SetMurderState(post)`.
   Adds **no** Harmony patches to vanilla enact/selection. Config: `[General] UnstickStalledMurders` (default
   true), `StallGameHours` (default 24 = in-game hours). **Resets on new game AND load** (see hard-won #2).

8. **Affair-pair dedup** (`FeudSim.Seed`). Pre-seeds `usedPairs` from `EventStore.All` (the just-seeded affairs)
   before seeding feuds/debts, so a pair that already has an affair never also gets a synthesized feud/debt —
   kills the "the victim was having an affair with the killer AND owed them money" over-determined overlap.

## Hard-won facts (don't re-learn)

1. **Do NOT trust `PlaceObject`'s `receiver`→"To" auto-resolution for these notes.** With `receiver=victim` the
   auto-created "To" **misresolved to an unrelated citizen** (the victim's affair partner) — almost certainly
   because the note reuses the **`DinnerLetter`** (love-letter) preset, whose "To" resolution appears
   romance-aware. Root cause was NOT our input (we passed the right person, *proven* because the explicit
   `AddCitizenConnection` using the same variable draws the correct link). **Rule: draw doc→citizen connections
   EXPLICITLY via `AddCitizenConnection` (direct `evidenceEntry` reference, no resolution) and set
   `receiver=null`.**

2. **Any transient per-game static must reset on BOTH new game AND load.** The watchdog's guards (`_intervened`
   etc.) reset only via `AffairSim.SeedForNewGame`, which is **skipped on load** (`ConsumeLoadSeedSkip` /
   `IsImportPending` return early in `Patch_OnStartGame_Seed`). Because humanIDs are reused across sandboxes, a
   victim id intervened-on in game A could be silently skipped after loading a different sandbox in the same
   process → a real soft-lock never recovers. **Fix: reset the watchdog at the top of `Patch_OnStartGame_Seed`,
   BEFORE the load-skip** (sibling modules survive load via rehydrate/replay; the watchdog has no persisted
   state, so it just clears). Found by the adversarial review — a good check to keep running before big commits.

3. **Murder enact = a combat DPS race during `executing`.** `MurderController.MurderState` =
   {none, acquireEuipment, research, waitForLocation, travellingTo, executing, post, escaping, unsolved, solved}.
   The kill lands during `executing` then flips to `post`. `MurderWeaponPreset.attackDamage` (Vector2) is lerped
   by `attackDamageLerpSource` (a `StatMultiplier`, e.g. `combatSkill`); `Actor.RecieveDamage(..., bool
   enableKill=false, ...)` only kills when `enableKill=true`. A weak weapon (`WeaponType.blade` = razor) + an
   awake/fleeing victim + a low-combat forced killer = a non-lethal loop with **no "failed" state** → soft-lock.
   `RedGumsKiller` is the MO that surfaced it (also the two homeless-stall cases). `Actor` exposes
   `currentGameLocation` / `currentRoom` / `currentBuilding` / `currentHealthNormalized` / `currentNode`
   (co-location + health gates); `SessionData.Instance.gameTime` is the in-game clock (hours). Decompiles saved
   this session in scratchpad `decomp-murder/` (MurderController, MurderMO, MurderWeaponPreset, MurderPreset,
   Actor, SessionData) — regenerate if stale.

4. **`isHandwriting` does not disable TMP rich-text / `<link>`** — clickable citizen links work in the
   handwriting-font notes (proven by the addressee link + the redundancy list using the same
   `RegisterCustomDocTree` path).

- **Applies to Affair, Promotion, Layoffs, Eviction.** Each such clue is **randomly EITHER a physical clue OR an

  redundant (gossip also names). Feud/Debt are excluded anyway.
